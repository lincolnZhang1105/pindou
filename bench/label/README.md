# bench/label：真值标注工具（T0.4）

本地网页工具。服务端是 Python 标准库 `http.server`，前端是原生 HTML/JS，不需要 node 构建；只监听 127.0.0.1。
真值格式见 `docs/04-recognition-benchmark.md` §2.2 和 `bench/README.md`。

## 启动

```bash
export PINDOU_DATA_DIR=/path/to/private/pindou-bench
PYTHONUTF8=1 .venv/Scripts/python -m bench.label serve            # 默认端口 8765，加 --open 自动打开浏览器
```

浏览器打开 <http://127.0.0.1:8765/>，右上角「我是」填你的名字（导出时记为标注人 / 复核人）。左侧是任务列表
（manifest 里的图纸；分页图一组是一个任务），可以按 dev / test、状态筛选。

| 状态 | 含义 |
|---|---|
| 未标 | 还没有草稿 |
| 草稿 | 有草稿，图例还没录 |
| 图例校验失败 | 图例颗数和格子里的实际颗数对不上 |
| 草稿（可导出） | 图例校验通过（或标了「无图例」），还没导出 |
| 待复核 | 已导出，但这是 XL 档或分页图，需要第二个人复核 |
| 完成 | 已导出（需要复核的已复核） |
| 真值无效 | labels/ 里的文件校验不通过（一般是被手工改过） |

## 标一张图（目标：58×53 的图 10 分钟内）

1. **网格**（右侧「网格」页）：行列数一般已从登记信息带出来，没有就填上点「应用」。按 `G` 进入网格工具，
   拖动四个橙色角点对准图纸**最外圈的格线**（滚轮放大后对准，误差控制在 1/4 格以内），然后点**「吸附网格线」**：
   每条线自动吸到图上的格线，粗线、累积漂移都能处理。检查最后几行几列是否对齐。
   - 个别线没吸准：拖动它。拖动的线变成锚点，相邻锚点之间的线按比例均分；`Shift`+拖动只动这一条。
   - 「均分」= 在当前外框内重新均分；「清除锚点」= 只保留首尾两条。
2. **图例**（「图例」页）：把图上的图例照抄进批量框，例如 `A1 x102, A11 x2, H7 718`，点「解析并合并」。
   **颗数必须照图抄，不要从格子里数**——图例是校验和。图纸本身没有图例时勾「无图例」。
3. **取色**：点第一行的「取色」，然后在图上依次点每个色号的图例色块，点完一个自动跳到下一行。
   图例里看不清的颜色（比如白色 H2），点一个该色号的格子也行。最后点「空格颜色」的「取色」，在图上点一个空格。
4. **自动填充**（「初稿」页）：点「自动填充」。每格取中心区域颜色的中位数，按 CIEDE2000 找最近的色块；
   **白豆和空格颜色一样时，按格内有没有色号文字区分**。拿不准的格子会标成可疑格（红框）。
   - 也可以从预测结果导入初稿（`$PINDOU_DATA_DIR/preds/<run>/<id>.json`，比如 baseline 的输出），不确定的格子同样标红。
5. **检查和修正**：看顶栏的图例状态和「图例」页的表格（实际颗数和图例对不上的标红，不在图例里的色号单独列出）。
   - `N` 跳到下一个可疑格，改掉或按 `X` 标为已处理；`H` 只高亮画笔色号，方便找漏涂的。
   - 涂色：输入色号回车（或在图例表里点一行、按数字键选最近用过的）→ 点击或拖动；`E` 是空格；`F` 填充连通区域；`Alt`+点击吸管。
6. **导出**：图例校验通过后「导出真值」才可点。导出时服务端再用 `validate_label` 校验一遍，写到 `labels/<id>.json`。
   草稿一直自动保存在 `labels/drafts/<id>.json`，关掉浏览器下次接着标。

## 分页图（T4）

一组几张图是一个任务，整张图纸的格子统一编号。在「网格」页的「分页图布局」里填每页的行列数和每行几页，
点「按图片顺序排布」，会给每张图建一页并算好列偏移 / 行偏移（不规则的分页可以逐页改「当前页」的参数，或添加页）。
然后用 `PageUp` / `PageDown` 逐页对准外框、吸附。取色、自动填充、图例校验都是整张图纸一起算。

## 复核（XL 档和分页图，04 §2.2）

标注人导出后状态是「待复核」。**另一个人**打开这个任务，在右上角填自己的名字，逐格检查（可以直接修改），
确认后点「复核通过」：重新校验并导出，记录 `reviewed_by` / `reviewed_at`。复核人不能和标注人同名；
标注人之后再导出，复核记录会清空，需要重新复核。

## 快捷键

| 键 | 作用 |
|---|---|
| `G` / `B` / `F` / `I` / `S` | 网格 / 涂色 / 填充 / 吸管 / 取色 |
| `1`–`9` | 选最近用过的色号（顺序固定，新色号排到最前） |
| `E` | 画笔设为空格 |
| `/` | 输入色号，回车确定 |
| `Alt`+点击 | 吸管（涂色模式下） |
| `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） | 撤销 / 重做（涂色、填充、网格、导入、自动填充都可撤销） |
| `Ctrl+S` | 立即保存草稿 |
| `H` | 只高亮画笔色号 |
| `T` | 格内文字开关 |
| `[` / `]` | 色块叠加透明度 |
| `N` / `Shift+N` | 下一个 / 上一个可疑格 |
| `X` | 当前可疑格标为已处理 |
| `0` | 适应窗口 |
| `PageUp` / `PageDown` | 上一页 / 下一页 |
| 空格+拖动、右键或中键拖动 | 平移 |
| 滚轮 | 缩放（以鼠标位置为中心） |
| `L` | 任务列表开关 |
| `?` | 快捷键帮助 |

## 说明

- 坐标是原图像素（像素 i 占 [i, i+1)），按 EXIF 方向校正后的方向；HEIC 用 `python -m bench.collect convert` 转出的 PNG。
  图片按原分辨率加载，不缩小。
- 色号统一规范化（`A01` → `A1`）；混用其他品牌写成 `品牌:色号`（如 `ZG:ZG1`）。不在色卡（`palette_hint`）里的色号导出时会提示。
- 导出的真值除了 04 §2.2 的字段，还有 `needs_review`、`annotator`、`labeled_at`、`reviewed_by`、`reviewed_at`；无图例时 `legend` 是空数组。
- 草稿里另外保存取色点、锚点、可疑格、最近色号等编辑状态，不进真值。
- 安全：只监听 127.0.0.1，校验 Host 头；写接口只收 `application/json`；路径参数只允许 `[A-Za-z0-9_-]` 且必须在 manifest 里。
