## 1. 定位

**一句话：识别最准、绝不背刺的拼豆助手。**

- **首发的首要人群**：核心玩家（S2）。
- **第二波人群**：智能板用户（S3）。等智能板功能 H1 上线、并且拿下至少一家方案商之后，再集中去争取这批人。**首发版本不能连接智能板**，原因见第 3 节的 H 组。
  - ✅ 已确认（产品负责人，2026-10-27）：首发只面向核心玩家，智能板放到首发之后。H1 保持 P1，对应任务 T3.1。
- **次要人群**：新手（S1）。用免费的「照片转图纸」吸引他们，再把他们转化成核心玩家。
- **主场景**：在小红书上找到图纸，保存原图，然后导入并识别，接着高亮跟拼（之后还可以连接智能板），拼完扣减库存、提醒补豆。
- **差异化**（按重要性排序）：
  1. **识别准确率**，尤其是大图、糊图、带水印的图纸。用 benchmark 数据说话，见 `04`。
  2. **不背刺的付费设计**：写成公开承诺，见第 2 节。
  3. **库存可以迁移**：能导入竞品的库存数据，方便用户「搬家」。
  4. **连接智能板免费**。这一条只是和竞品拉平：颂拼豆、拼豆大王已经免费；AI 豆仓收 ¥48，我嘞个豆要积分。真正的差异在于能连哪些板子、连上之后体验好不好。
  5. **识别在端侧完成**：离线可用，隐私更好，边际成本为零。

## 2. 产品承诺

这几条会写进 App 内的「我们的承诺」页面和应用商店描述，**工程实现必须遵守，并且要有测试覆盖**。

1. **免费额度只增不减。**
   - 免费额度统一定义在 `free_limits.json` 里。
   - CI 会拿它和上一个发布 tag 对比，任何一个数值变小，构建就失败。
2. **你的图纸永远属于你。**
   - 会员过期后，已导入的图纸照样可以查看、跟拼、高亮、编辑、导出（导出能力按免费档来）。
   - 详细规则见第 4 节「会员过期后」一列。
3. **支持全量导出和导入。**
   - 图纸、库存、进度都能导出为开放格式：JSON 备份、CSV、PNG。
   - 也能从 JSON 备份恢复（功能 I4），换手机时不依赖登录和云同步。
4. **永久会员不和订阅混卖。**
   - 用户购买永久会员时，如果还有生效中的自动续费订阅，要明确提示，并引导他去取消（iOS 跳转到系统的订阅管理页）。
   - 自动续费的全部规则按 `06` 第 5 节第 1–7 条执行。
5. **连接智能板永远免费。** 连接智能板的代码路径**不能读取任何权益信息**，用静态检查或单元测试来保证。
6. **不弹开屏广告，不搞邀请码裂变。** 激励视频只在用户主动点击时播放。
   - 识别、跟拼、库存、导出这些免费功能，**永远不需要登录**。
   - **只有购买会员时需要登录**（手机号或 Sign in with Apple），用于恢复购买和跨设备同步权益。

      │                                         ├ 顶部：58×53 · 12 色 · 1885 颗 · 与图例完全一致 ✓ / 差 3 颗
      │                                         ├ 画布：不确定格加黄框，可以「下一个」逐个跳转
      │                                         └ 网格不对？→ [手动校正网格（多页时按页校正）]

   ├─▶ [编辑]   ├─▶ [导出]

[库存]：色卡网格（显示余量条）→ 入库 / 出库 / 补豆清单 / 迁移
[我的]：会员（登录入口）、我的自动续费、我们的承诺、备份导出导入、设置、关于、开源许可、客服、注销
```

```

               grants: [{product_id, kind: auto_renew|one_off|lifetime|ad_reward, source: appstore|wechat|alipay|ad,
                         starts_at, expires_at?, original_txn_id, status: active|refunded|revoked}],
               credits: [{amount, origin: purchase|gift, txn_id, expires_at?}] }
               // 会员档位由 grants 推导；购买来的积分没有 expires_at

## 7. 非功能需求

- **离线**：识别、跟拼、库存、导出在断网状态下全部可用。
- **性能**（中端机）：
  - 识别一张 104×104 的图纸 ≤ 3 s；
  - 跟拼模式在 208×208 的图纸上保持 60fps；
  - 冷启动 ≤ 1.5 s；
  - 识别时的内存峰值 ≤ 200 MB（大图分块处理）。
- **数据安全**：数据保存在本地；破坏性操作之前自动做快照；支持备份导出和导入。
- **可访问性**：色号文字始终可以显示，照顾色弱用户。
- **平台**：
  - iOS 15+、iPadOS、Android 8+；
  - 首发时 iOS 和 Android 同时上线；
  - 安卓首批上架华为、OPPO、vivo、应用宝，等公司主体办好再上小米、荣耀；
  - 鸿蒙原生版放到后期。
- **合规**：
  - 隐私同意之前不初始化任何 SDK；
  - 「关于」页显示备案号；
  - 有「开源许可」页；
  - 只使用 `06` 第 7.1 节白名单里的 SDK。

## 8. 核心指标

| 指标 | 定义 |
|---|---|
| 激活 | 新用户中，完成第一次识别并进入跟拼模式的比例 |
| 识别可信度 | 平均每张图纸被用户手动修改的格子数；图例一致率 |
| 留存 | D1 / D7 / D30；每周跟拼会话数（由自建埋点上报到后端统计） |
| 付费 | 转化率；永久会员和订阅的销量比例；退款率 |
| 口碑 | 应用商店评分和差评关键词；小红书自然提及量 |
