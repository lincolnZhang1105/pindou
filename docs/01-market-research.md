- 玩家人数可能会回落，但核心玩家会留下来，所以产品要服务好留存下来的核心人群。

**结论：**
- 「照片转图纸」已经被平台官方工具和通用 AI（GPT / 千问的提示词玩法）免费覆盖了，**不能作为收费点**。
- 竞争焦点在三件事上：**识别准确率、跟拼体验、库存，以及连接智能板**。

## 3. 用户分群

| 分群 | 描述 | 怎么找到我们 | 付费意愿 |
|---|---|---|---|
| S1 新手 / 路人 | 想把照片或喜欢的图片转成图纸，用得少 | 应用商店搜索、小红书 | 低；很反感太早出现的付费墙 |
| **S2 核心玩家** | 在小红书、抖音找画师的图纸；要识别、高亮、库存；会同时囤几百张图纸 | 小红书评论区口碑 | **中到高**；偏好永久会员（¥28–88），会拼单分摊 |
| **S3 智能板用户** | 买了智能拼豆板，需要一个好用的 App 来连接 | 随板说明书、店家推荐、小红书 | 高（愿意为连接付费，但讨厌被额外收费） |
| S4 拼豆店主 | 店里配了智能板，让顾客扫码下载 App | 板子厂商、同行 | 中；做 B 端版本可以作为附加收入 |
| S5 画师 | 发布图纸，想获得曝光，也在意版权 | 小红书 | 内容供给方，不是付费方 |

**首要目标人群：S2 和 S3。** S1 通过免费的生成功能来引流。

## 4. 核心玩家的真实工作流

```
在小红书/抖音刷到画师图纸
  → 复制链接或保存图片
  → 导入 App
  → AI 识别网格和色号（经常要人工修正）
  → 存进图纸库（一次囤几百张）
  → 开拼：单色高亮，标记已完成；或者连接智能板
  → 拼完后出库，扣减库存
  → 收到补豆提醒，下单补货
```

用户原话：「我一般在小红书上找，然后复制链接」（147 赞）。还有：「很多老师不在这些拼豆软件上发图纸」。

## 5. 痛点清单（附证据）

### 5.1 识别（第一痛点，也是第一付费理由）

- **大图识别不行**：104 或 208 格的大图，越往上网格越对不齐（《拼豆软件太难用了》）。AI 豆仓把 208×208 识别成了 76×77，上传时还把图压缩了（《浅谈一下拼豆大王和 ai 豆仓图纸识别》）。
- 图糊、有水印的格子识别不出来；**错一颗就得在几千颗里人工找**。有用户说：「不相信任何 AI 小程序 App，大图如果一个不注意识别错了，还得自己费劲去找出错的那个豆子」（97 赞）。
- 被夸的细节：
  - 先读图纸底部的色卡图例再识别（拼豆大王）
  - 能定位到识别不出的格子（AI 豆仓）
  - 识别完给出「全部一致」的提示
- 用户会为准确率付费：「用了 ai 豆仓和拼豆大王，果断买了大王永会，识别真的比豆仓准很多」。
- 实测原因（见 `04-recognition-benchmark.md` 第 1 节）：小红书下发的图片宽 1000–1080px，图纸一大，每格只剩几个像素，色号文字根本读不出来。

### 5.2 付费体验（App Store 和小红书双重证据）

- **付费墙出现得太早**：App Store 上「拼豆画」51 条差评几乎都在骂「用一次就要会员」。
- **付了钱却用不了**：「充完会员一张都生成不出，全空白」「客服装聋」「未成年消费退款找不到人」。
- **背刺比收费更招恨**：
  - 免费额度缩水（豆猫）
  - **会员过期后已导入的图纸被锁**（AI 豆仓：「存了几百张图纸都点不开」）
  - **买了永久会员，月订阅仍在扣费**（AI 豆仓）
  - 试用到期自动续费前没有提醒
- 连接智能板单独收费会招来反感（AI 豆仓收 ¥48，我嘞个豆要 2999 积分）；反过来，拼豆大王把「连板免费」当成卖点。
- 邀请码和积分体系污染社区：热评第一是「不要打广告不要发邀请码了」。但我嘞个豆靠这套打法确实拿到了最多的推荐。

### 5.3 跟拼体验

- 想要的高亮方式：高亮一个色号时，其他格子依然显示色号；高亮背景随色号变色；同时对比两个颜色的位置。
- 已完成和未完成分开显示；拼完的色号持续保留显示；标注每行、每列的豆子数量。
- 能自定义网格起点；能镜像（用美纹纸转移时需要）；**iPad 横屏**；放大缩小要流畅不卡。

### 5.4 库存

- 不知道一包到底有多少颗（初始数量不确定）；手动一颗颗扣减太烦；希望按图纸一键出库。
- 很多人用 Excel、飞书，或让 AI 手搓一个库存表。说明这是真实需求，但现有工具没满足好。
- **迁移成本高**：「我已经在习惯用的 App 上记录了很多次出入库……改用新 App 无法导入现有豆子数量」。

### 5.5 预览失真

- 「永远不要相信拼豆软件的预览图纸」：白色网格线让预览显得比实物亮；灰暗的肤色色号会被映射错，实物拼出来很难看。

### 5.6 图纸编辑

- 图纸要能重命名、拆图、合图、挪位置、二次编辑。
- 用户期待「照片转图纸、AI 抠图、编辑、导出、辅助拼豆、豆仓余额、图纸核销全部做成一套」（《为什么没有好用的拼豆软件！？》）。

### 5.7 其他

- 交互：删除按钮和画布点击区重叠导致误删；图层系统难懂；没有自动保存，作品丢失；卡顿。
- 打印：打印出来的图纸和实际尺寸不符；用户要 1:1 实际尺寸打印、按板子分页打印。
- 平台：安卓用户找不到只有 iOS 版的好用 App；平板适配不好。

## 7. 数据采集方法（可复现）

| 数据 | 方法 | 文件 |
|---|---|---|
| App Store 竞品 | iTunes Search API：`https://itunes.apple.com/search?term=<URL 编码>&country=cn&entity=software&limit=50`，关键词为 拼豆 / 拼豆图纸 / 拼豆图纸生成器 / 拼豆像素画 / 拼豆助手 / perler | `data/appstore/competitors.csv` |
| App Store 评论 | `https://itunes.apple.com/cn/rss/customerreviews/page=N/id=<id>/sortby=mostrecent|mosthelpful/json`。接口不稳定，经常返回空 feed，要加延时并重试另一种 sortby；20 个 App 里只拿到 10 个的评论 | `data/appstore/reviews.jsonl`（393 条） |
| GitHub 项目 | Search API，关键词为 perler / fuse beads / hama / 拼豆 / pindou / mard 等，加上 topic 搜索 | `data/github/repos.csv` |
| 小红书 | 通过 CDP 控制已登录的 Chrome。搜索 URL 为 `https://www.xiaohongshu.com/search_result?keyword=<编码>&source=web_explore_feed`；列表项选择器 `section.note-item`；详情页标题 `#detail-title`、正文 `#detail-desc`，评论 `.comment-item .content .note-text`。**必须登录**，出口 IP 在海外时会被重定向到 rednote.com。每条笔记只拿到前 10–30 条热评 | `data/xhs/notes_index.csv`（125 条）、`data/xhs/notes_detail.jsonl`（41 条，含正文和热评） |
| 图纸样例 | 从笔记详情页取 `xhscdn.com` 图片 URL，带 Referer 头下载，WebP 转 PNG | `data/samples/` |

**关于采集方式的说明：** 调研阶段在用户已登录的浏览器里，以接近人工的节奏读取了 41 条公开笔记，只用于内部的需求分析。**工程阶段不再使用任何自动化抓取**，benchmark 样本一律人工保存（见 04 第 2.1 节、06 第 9 节）。

**偏差说明：**
- 小红书搜索结果受个性化推荐影响，「避雷」类关键词会放大负面声音。
- App Store 评论样本里「拼豆画」占比偏大，差评比例可能被高估。
- 小红书每条笔记只读了热评，没有读全部评论。
