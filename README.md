# 豆伴（暂定名）：拼豆工具 App 项目方案包

> 生成日期：2026-10-27（v0.2，已根据独立的一致性审查修订）。
> 这份方案包同时写给两类读者：一是做决策的人，二是负责工程实现的 AI。给 AI 的执行说明见 [AGENTS.md](AGENTS.md)。

## 一页纸结论

- **做什么**：一个识别最准、绝不背刺的拼豆助手。
  - 首发瞄准小红书上的核心玩家。智能板用户是第二波目标，等智能板功能上线后再争取。
  - 主流程：在小红书保存原图 → 导入 → 端侧识别 → 高亮跟拼 → 管理库存、提醒补豆。
- **不靠什么赚钱**：照片转图纸。小红书官方的「RED 拼豆图纸工坊」免费且不限次数，GPT 类工具也能做，这个功能只用来引流。
- **靠什么赚钱**：会员。
  - 会员权益：图纸库不限量、库存自动化、PDF 打印、云同步、从竞品迁移数据。
  - 价格（初始假设）：月 ¥8、年 ¥48、永久 ¥68。核心玩家对永久会员的心理价位在 ¥28–88。
- **差异化**：
  1. 识别准确率，尤其是大图、糊图、带水印的图纸；
  2. 公开的「不背刺承诺」。竞品主要就是败在背刺用户上；
  3. 能从竞品迁移库存；
  4. 智能板免费连接。这一条只是和竞品拉平，真正的差异在于能不能谈下更多方案商；
  5. 端侧识别：离线可用，边际成本为零。
- **形态**：
  - Flutter App（iOS、iPad、Android 同时首发）；
  - C++ 识别核心 `beadcore`（OpenCV + ONNX Runtime，自己训练的小模型）；
  - **一个最小后端**：负责账号、订单、验签、权益和埋点，部署在境内云服务器上，并做 ICP 备案；
  - 暂不做小程序。
- **最大风险是识别准确率**：所以第一阶段先做 6 周 benchmark。**如果在同一批难图上赢不了最强的竞品，就不入场**，见 [04](docs/04-recognition-benchmark.md)。
- **时间窗口**：拼豆热潮可能在 2026 年下半年到 2027 年上半年退潮。产品要服务好留下来的核心玩家，定价上突出永久买断和年付。

## 关键约束和取舍（详见 06）

| 事项 | 决定 | 原因 |
|---|---|---|
| 主体 | **一人有限公司**，go 之后立即注册 | 主流广告联盟、支付宝扣款、小米和荣耀上架都只接受企业 |
| 粘贴链接抓图 | **不做**；benchmark 采集也只靠人工保存 | 平台协议禁止抓取，新版《反不正当竞争法》有数据条款，已有刑事判例。代价是比竞品少一个便利功能 |
| 账号 | 免费功能永远不需要登录；**只在购买会员时登录** | 安卓的单次购买和跨端权益都需要用户身份 |
| 安卓收费 | 首版只卖单次购买（月卡、年卡、永久） | 代扣的准入门槛，新 App 达不到 |
| iOS 收费 | 自动续期订阅 + 非续期订阅 + 永久 + 积分；加入小型企业计划 | 中国区标准佣金 25%，小型企业计划 12% |
| AI 生图 | P2，需要公司主体和全套资质 | 要求算法备案、安全评估、标识、实名；核心功能用确定性算法 |
| 权限 | 相册不申请；首发不声明蓝牙；通知等到首次购买后才申请 | 合规，也避免被判「超范围申请权限」 |
| SDK | 首发只用微信、支付宝、sentry_flutter（上报到自建 GlitchTip） | 用户拒绝隐私政策时进入「基础模式」，照常可用 |
| 色卡数据 | MARD 和国际品牌用 maxcleme/beadcolors（MIT）；国内其他品牌逐套核实来源 | 部分公开数据派生自 AGPL 项目 |
| 智能板 | 首发之后上线；优先谈合作；不绕过鉴权 | 详见 03 附录 A.4 |

## 需要产品负责人拍板或咨询律师的事项

**已拍板：**
- ✅ 首发只面向核心玩家，智能板（H1）放到首发之后（2026-10-27 确认，见 02 第 1 节）。

**待定：**
1. **阶段 0 的 go/no-go 结论**（判定条件见 04 第 0 节）。
2. **智能板商务合作**：I-ledshow、Heaton、酷猫（03 附录 A.4）。
3. **需要律师意见的事项**：
   - Heaton 系逆向协议能否接入；
   - 色卡数据的来源问题；
   - 云同步副本的版权问题；
   - u2netp 模型权重的许可；
   - 以及 06 第 13 节列出的其他事项。
4. **产品正式名称和商标检索**：应用名、备案名、软著名三者要一致（任务 T2.2）。
5. **MARD 等国内品牌的色值来源**（T0.2 新发现，2026-10-27）：原定的 MARD 主数据源 maxcleme/beadcolors，其 MARD 数据和 Zippland（AGPL）高度重合，COCO、漫漫、盼盼、咪小窝也都没有来源可确认的色值（见 `palettes/SOURCES.md`）。识别不受影响（靠图例），但照片转图纸和平替推荐用不了这些品牌。建议：
   - 请法务判断色号、色值这类事实性数据能否使用；
   - 同时把「自建色卡」提前到上线前：买实物色卡，用色度计自测（每个品牌约 1 个工作日 + 色度计采购）。
